Payment must be linked to your logged-in Supabase user. This page binds your user id into PayPal via: custom_id = uid|course_id and a unique invoice_id.
How activation works
1) You pay via PayPal (capture).
2) PayPal sends a webhook event (PAYMENT.CAPTURE.COMPLETED) to your Supabase Edge Function.
3) The webhook handler verifies the signature, logs the event idempotently, and upserts public.purchases for your user.
4) This page polls for that purchase row and redirects you to the intended course page.
Expected Entitlement Row
purchases.user_id = auth.uid(), purchases.course_id = <course_id>, purchases.paid = true
If you paid and access is not visible yet, it is usually because the webhook hasn’t processed the event yet (delivery delay) or your purchases table RLS policy blocks reads.
Troubleshooting (fast)
If you see “Paid but no access”:
• Confirm you are logged in with the same email you used during payment.
• Wait ~10–30 seconds and click “I’ve Already Paid — Check Access”.
• In Supabase, check public.paypal_webhook_events for the latest event and whether processed=true.
• Confirm the purchase row exists in public.purchases with paid=true and correct course_id.

If your purchases table has RLS enabled:
Make sure you have a policy that allows authenticated users to read their own rows: using (auth.uid() = user_id).
